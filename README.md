# The Solutionists

AI-first startup project for **HackIndia 2026**.

We are building and validating a real startup product using AI-first development workflows.

> **Current direction:** AI Revenue / Sales Intelligence

---

## Current Direction

We are exploring an AI-powered workflow that helps small B2B companies reduce the manual work involved in:

- Finding potential customers
- Researching prospects
- Qualifying leads
- Preparing personalised outreach

### Initial Target Customer

Small/early-stage B2B SaaS companies with limited or no dedicated sales teams.

### Initial MVP Hypothesis

```text
Company + Ideal Customer Profile
              ↓
       Prospect Discovery
              ↓
      AI Research & Qualification
              ↓
       Prioritised Prospects
              ↓
     Personalised Outreach
```

This direction is currently being validated through customer, competitor, technical, and business research.

## Project Workflow

We use GitHub as the central workspace.

| Tool | Purpose |
|---|---|
| Issues | Individual tasks and deliverables |
| Projects | Track team progress |
| Milestones | Track major project phases |
| Discussions | Team discussions and important decisions |
| Pull Requests | Code review and integration |
| docs/ | Permanent project documentation |

### Task Ownership

Every task has one owner.
Team members can collaborate, but the assigned owner is responsible for the deliverable.

### Development Workflow

```text
Issue
  ↓
Branch
  ↓
Implementation
  ↓
Pull Request
  ↓
Review
  ↓
Merge
```
